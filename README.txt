THIỆP CƯỚI ONLINE - BẢN MẪU TĨNH

1. Mở index.html bằng Chrome để xem thử.
2. Sửa thông tin cặp đôi, ngày cưới, nhà hàng, bản đồ trong CONFIG ở script.js.
3. Sửa nội dung chữ trong index.html và màu sắc trong style.css.
4. Thay ảnh: tạo thư mục images, thêm ảnh và sửa các khối .photo trong HTML thành thẻ <img> hoặc CSS background-image.
5. Muốn có nhạc: tạo thư mục music, đặt file nhacnen.mp3 vào đó. Trình duyệt chỉ phát sau khi khách bấm mở thiệp hoặc nút nhạc.
6. Link riêng cho khách: index.html?to=Nguyen%20Van%20A
7. RSVP và lời chúc đang lưu localStorage trên chính thiết bị khách, CHƯA gửi về một cơ sở dữ liệu chung.
8. Khi hoàn thành, tải thư mục này lên Cloudflare Pages hoặc dịch vụ host website tĩnh.

Lưu ý: ngày giờ trong phần nội dung HTML hiện là dữ liệu mẫu, phải sửa đồng bộ với CONFIG.weddingDate.
