THIỆP CƯỚI MINH TOÀN & HUYỀN NI | TÔNG TRẮNG HỒNG

1. Mở index.html để xem thử (nên dùng VS Code Live Server).
2. Để nhạc hoạt động, chép file nhạc của bạn vào music/runtoyou.mp3.
3. Logo tab nằm tại pics/lg.png. Có thể thay bằng file lg.png của bạn.
4. Đổi thông tin trong phần CONFIG đầu script.js.
5. Link khách mời: https://TEN-TRANG-CUA-BAN/?to=Nguyen%20Van%20An
6. Upload toàn bộ file/thư mục lên GitHub repository đang bật GitHub Pages.
7. Form RSVP và lời chúc hiện chỉ lưu localStorage của từng thiết bị,
   KHÔNG gửi thông tin về cho chủ tiệc. Muốn thu thập online cần dịch vụ
   lưu dữ liệu như Google Forms, Google Sheets/Apps Script, Firebase, v.v.
8. Muốn hiện ảnh khi chia sẻ qua Zalo/Facebook, tạo ảnh share.jpg 1200x630
   và thêm URL tuyệt đối vào og:image trong index.html.

Mẫu này là thiết kế mới lấy cảm hứng phong cách vườn hoa hồng,
không sao chép mã nguồn hoặc tài sản của website tham khảo.
